# BACKLOG — لوحة كانبان (آخر تحديث: 9 نوفمبر 2026)

مصدر البنود: ملاحظات المستخدمين الفعليين + طلبات المالك. القاعدة: **لا بناء لبنود «تحتاج تحليلاً» قبل تحليل المنافسين** (المالك سيزوّد تسجيلات شاشة)، ولا دفع/نشر قبل موافقة المالك.

## مبادئ السلاسة (تُراجَع بعد تحليل المنافسين)
1. المسار اليومي (تسجيل وجبة) لا يزيد نقرات؛ أي ميزة جديدة تُخفى خلف «المزيد» أو تظهر عند الحاجة فقط (إفصاح تدريجي).
2. **نموذج بيانات واحد:** الوصفة = صنف مركّب، فتعمل معها كل الشاشات الحالية (بحث، وجبة، صوت، تسوّق) بلا تفرّع.
3. لا حجب ولا إلزام: التنبيهات (حساسية، مراجعة هدف) تحذّر وتقترح ولا تمنع.
4. التعديلات تسري من اليوم فصاعداً؛ الأيام السابقة مجمّدة (انظر `freezePast`).
5. كل ميزة خلف مفتاح `feat()` (يتحكم به المدير)، ولها اختبارات jsdom، وتُنشر صغيرة.
6. كل ما يخص التغذية الطبية (حمل/رضاعة/حساسية) إرشادي، ومصدره موثّق، مع نص «استشر طبيبك».

## 🟡 يحتاج تحليل منافسين + قرار قبل البناء
| # | البند | الجهد | ملاحظات التصميم |
|---|---|---|---|
| A1 | **وصفاتي** (كيكة، حلى البسكويت…): مكوّنات بكميات + وزن الناتج + عدد القطع/الحصص + صورة + طريقة تحضير. تُستدعى كصنف (100 جم / قطعة / حصة). «حضّرها»: تعيد حساب الكميات لعدد القطع أو الوزن. مشاركة نصية. حفظ من وجبة أو من الصوت | L | الماكروز محسوبة دائماً من المكوّنات؛ تعديل مكوّن لا يغيّر الأيام الماضية؛ الصورة تُصغَّر على الجهاز؛ قرار: مزامنة الصور مع Supabase أم محلياً |
| A2 | **تفضيلات الأصناف:** ⭐ مفضّل، 🚫 غير مفضّل، ⚠ حساسية (غلوتين، ألبان، مكسرات، بيض، سمك، صدفيات، صويا، سمسم…) لكل مشارك | L | المفضّل يتقدّم في القوائم ويُفضَّل في الخطة والبدائل؛ غير المفضّل لا يُقترح؛ الحساسية: وسوم على الكتالوج (CAT) والأصناف المخصّصة (+ حقل allergens من OFF وقراءة الملصق)، وتحذير عند الإضافة لا حجب. تنبيه صريح أن الوسوم قد تكون ناقصة |
| A3 | **حساب الأنثى: حمل ورضاعة** في الأهداف (نمط/ثلث الحمل، رضاعة كاملة/جزئية) تزيد السعرات والبروتين، وتمنع اقتراح عجز حاد، وتعرض ملاحظة طبية | M | الأرقام من مصدر موثّق (IOM/منظمة الصحة/وزارة الصحة السعودية) يُتحقق منها قبل التنفيذ؛ أسفل حدّ يومي؛ يظهر فقط عند اختيار الجنس أنثى |
| A4 | **الدعم الفني داخل التطبيق:** زر «أبلغ عن مشكلة» (وصف + تصنيف + إرفاق النسخة والجهاز والأخطاء بلا بيانات أكل) ← جدول `mp_tickets` (RLS) ← لوحة الإدارة + زر واتساب. تحليل البلاغات بمهمة مجدولة لـ Claude تعدّ اقتراحاً فقط، ولا تعديل ولا نشر إلا بموافقة المالك | M | قرارات: واتساب فقط أم شات داخلي؟ رقم واتساب؟ هل يرى المستخدم الردود؟ |

## 🔵 حاجز (Gate)
**G1 — تحليل المنافسين** (تسجيلات شاشة من المالك على درايف، مجلد واحد، أقل من دقيقتين لكل رحلة): نقارن تسجيل وجبة، الأصناف والوصفات، المفضّلة/الحساسية، الحمل والرضاعة، المشاركة، الدعم. مخرجه: تعديل مبادئ السلاسة وتثبيت تصميم A1–A4 قبل أي بناء.

## ترتيب مقترح
1. نشر `voice-port` (بعد موافقة المالك) ← 2. R1 ← 3. R2 ← (بالتوازي G1) ← 4. A1 وصفاتي ← 5. A2 التفضيلات ← 6. A3 الحمل والرضاعة ← 7. A4 الدعم.
