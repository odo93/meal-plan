# نظام الوجبات الأسبوعي

صفحة واحدة (`index.html`) بلا خادم ولا تثبيت. تعمل محلياً بفتح الملف، وتُحفظ بياناتك في المتصفح. المزامنة السحابية اختيارية.

## 1) النشر المجاني

### GitHub Pages
1. أنشئ مستودعاً جديداً على GitHub (اسمه مثلاً `meal-plan`).
2. ارفع الملف `index.html` (Add file ← Upload files).
3. Settings ← Pages ← Source: **Deploy from a branch** ← Branch: `main` / root ← Save.
4. بعد دقيقة يظهر الرابط: `https://<اسمك>.github.io/meal-plan/`
   - الحسابات المجانية تنشر Pages من المستودعات **العامة** فقط. الصفحة لا تحتوي أي بيانات شخصية؛ بياناتك في متصفحك أو في Supabase.
   - لمستودع خاص: استخدم Cloudflare Pages أو Netlify (كلاهما مجاني؛ اسحب الملف إلى لوحة التحكم).
5. على الجوال: افتح الرابط ← مشاركة ← «إضافة إلى الشاشة الرئيسية».

### تحديث الصفحة لاحقاً
استبدل `index.html` في المستودع بالنسخة الجديدة (Upload files ← Commit). بياناتك لا تتأثر لأنها مخزّنة خارج الملف.

## 2) قاعدة البيانات والمزامنة (Supabase، الخطة المجانية)

1. أنشئ مشروعاً على https://supabase.com (الخطة المجانية تكفي).
2. SQL Editor ← الصق محتوى `schema.sql` ← Run. (آمن للتكرار.)
3. Authentication ← Providers ← Email: فعّله. للتبسيط يمكنك إيقاف «Confirm email» أثناء التجربة.
4. Project Settings ← API: انسخ **Project URL** و**anon / publishable key**. لا تستخدم `service_role` أبداً داخل الصفحة.
5. في التطبيق: إعدادات ← «المزامنة السحابية» ← الصق الرابط والمفتاح ← أدخل بريداً وكلمة مرور ← «إنشاء حساب» ثم «تسجيل الدخول».
6. «رفع الآن» يرسل كل المستخدمين والخطط وسجل الأيام. «تنزيل من السحابة» يستبدل بيانات هذا الجهاز بما في السحابة (بعد تأكيد). «رفع تلقائي» يرفع بعد كل تعديل بنحو 4 ثوان.

### ملاحظات
- كل صف مرتبط بحسابك وحدك عبر RLS (`owner = auth.uid()`)، فلا يراه غيرك حتى لو عُرف المفتاح العام.
- الرفع «مرآة»: ما تحذفه محلياً (مستخدم أو يوم سجل) يُحذف من السحابة عند الرفع التالي. المزامنة تتم بالجهاز الأحدث؛ لا يوجد دمج تلقائي بين جهازين يعدّلان معاً، فاستخدم «تنزيل» قبل أن تبدأ على جهاز آخر.
- الخطة المجانية تُوقف المشروع مؤقتاً بعد نحو أسبوع بلا نشاط (يعود بضغطة من لوحة التحكم). بياناتك تبقى.
- الجداول: `mp_users` (الإعدادات والأصناف) و`mp_days` (7 أيام الخطة) و`mp_history` (الفعلي بالتاريخ). السجل بصيغة JSON لكل يوم، ويمكن لاحقاً بناء تقارير SQL عليه أو نقله إلى جداول مفصّلة.

## 3) إضافة صنف من صورة الملصق
زر «📷 صورة الملصق الغذائي» في تبويب الأصناف يشغّل قراءة النص داخل المتصفح (Tesseract.js، تحتاج إنترنت أول مرة). القراءة تقريبية، فراجع الأرقام قبل الإضافة. إن لم تنجح استخدم «📝 لصق نص الملصق»: في الآيفون افتح الصورة، اضغط مطولاً على النص، انسخ، ثم الصق.
